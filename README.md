
# Git and GitHub Collaboration Lab

## Description
This repository was created for a lab assignment to practise using Git and GitHub for collaborative work.

## Objectives
- Create and manage a GitHub repository.
- Collaborate with another student.
- Use branches to make independent changes.
- Submit and review pull requests.
- Merge approved changes into the main branch.

## What We Learned
This assignment demonstrates how Git and GitHub can be used to track changes, collaborate on a project, and review contributions before merging them into the main branch.
