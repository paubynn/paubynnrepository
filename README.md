
# Git and GitHub Collaboration Lab

## Description
This repository was created for lab 1.0 to practise using Git and GitHub for collaborative work.

## Objectives
- Create and manage a GitHub repository.
- Collaborate with another student.
- Use branches to make independent changes.
- Submit and review pull requests.
- Merge approved changes into the main branch.
